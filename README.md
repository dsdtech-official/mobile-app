# DSD TECH mobile apps

Information and user feedback for DSD TECH mobile apps.

| App | Platforms | Documentation |
|---|---|---|
| diBlue | Android and iOS | [diBlue](diBlue/README.md) |

## Feedback

Open [Issues](../../issues) and choose the diBlue problem report or improvement
form. Include your platform and app version so the report can be identified.
You need a GitHub account to submit an issue.

Issues are public. Remove personal information, device identifiers and sensitive
communication data from screenshots and logs before posting.

## Source code and downloads

The main branch contains documentation and feedback forms, not application
source code or installation packages. Historical reference source, when
published, is provided as a separately attached ZIP in a versioned Release.
See [diBlue](diBlue/README.md) for its Android 2.5.1 reference-source scope and
download status. It is not the source code of the latest store version.
