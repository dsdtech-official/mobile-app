# diSerial for Android

diSerial by DSD TECH is a USB serial terminal for Android phones and tablets.
It supports saved commands, live charts, and serial logs you can export.
USB serial features require an Android device with USB Host (OTG) support
and a compatible single-port USB serial adapter.
